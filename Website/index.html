Dictionary Notes

詞庫說明

使用者詞庫

data.txt

放你自己手動新增的詞、片語與專有名詞，格式是 phrase reading。它會影響候選詞，也會參與英文 prefix 判斷。

英文白名單

smart-mixed-ascii-words.txt

放產品名、縮寫與常用英文 run，一行一個 ASCII 詞，不需要讀音。它主要用來讓智慧混輸更穩地認出英文片段。

同步方式

patch sync

同步會先從本機 patch-source.json 指定的 Google Drive 下載最新詞庫，和本機變更合併；若也設定 writeback URL，還會把合併結果寫回雲端。同步前會先驗證格式，再備份舊檔。

Feature Map

目前可用功能

已完成

注音 / 英文混合模式

輸入中文時可直接插入英文片段，例如「今天Meeting改到下午」。支援大寫起始英文、常用小寫詞、全大寫縮寫與尾端數字。

部分完成

不按 Shift 的小寫英文

像 call、meeting、chrome、testing 這類合理英文 run 會延遲判斷並回溯成英文。

已完成

快捷加入個人詞庫

游標在詞尾時，用 Control + Shift + 數字 將前 N 個字元加入使用者詞庫；同位置重複可刪除。

已完成

雲端詞庫同步

不把私人白名單與詞庫放進公開 GitHub。每台 Mac 透過本機 patch-source.json 指向 Google Drive 下載連結；若需要多人共用，還可以加上 writeback URL。

How To Use

使用方法與熱鍵

下面是目前版本最重要的操作。熱鍵以 macOS 實際偵測到的 modifier flags 為準，尚未嚴格限定左側 Control / Shift。

ControlShift5

加入游標前 5 個字元

游標在 Cloud 的 d 後方時按下，會將 Cloud 加入使用者詞庫。

ControlShift2

加入游標前 2 個中文字

游標在「字尾」後方時按下，會將「字尾」加入使用者詞庫。

同位置同熱鍵

刪除剛加入的詞

同一位置再次按相同熱鍵，會從使用者詞庫刪除該詞，並顯示提示視窗。

輸入法選單

同步雲端詞庫

從 Google Drive 下載 data.txt 與 smart-mixed-ascii-words.txt，同步前會先驗證格式；若有 writeback URL，合併後也會回寫雲端。

Install

下載與安裝

目前提供個人測試用 DMG。它可以安裝在從未安裝過此輸入法的 Mac，也可以覆蓋舊版；安裝腳本會停止舊 process、替換 app bundle 並重新啟用輸入來源。

下載 Broccoli SmartInput v1.0.1 DMG 下載 PKG
  1. 打開 DMG，執行 Broccoli-SmartInput-v1.0.1-personal.pkg。
  2. 若 macOS 顯示「Apple 無法驗證」，對 pkg 按右鍵選「打開」。
  3. 安裝後到「系統設定 > 鍵盤 > 輸入方式」確認花椰輸入法已加入。
  4. 若行為仍像舊版，登出再登入或重開機一次。
  5. 如果打開 DMG 後執行 PKG 碰到困難，請直接使用下方終端機指令，複製貼上即可完成安裝。

Advanced

終端機指令

完整安裝指令

xattr -dr com.apple.quarantine /Volumes/Broccoli-SmartInput-v1.0.1-personal/Broccoli-SmartInput-v1.0.1-personal.pkg
sudo installer -pkg /Volumes/Broccoli-SmartInput-v1.0.1-personal/Broccoli-SmartInput-v1.0.1-personal.pkg -target /

同步雲端詞庫指令

若你已經完成安裝，也可用同一個輸入法選單同步雲端詞庫：

/Users/$USER/Library/Input\ Methods/McBopomofo.app/Contents/MacOS/McBopomofo patch sync
/Users/$USER/Library/Input\ Methods/McBopomofo.app/Contents/MacOS/McBopomofo patch check-release
