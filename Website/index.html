Dictionary Notes

詞庫說明

使用者詞庫

data.txt

放你自己手動新增的詞、片語與專有名詞，格式是 phrase reading。它會影響候選詞，也會參與英文 prefix 判斷。

英文白名單

smart-mixed-ascii-words.txt

放產品名、縮寫與常用英文 run，一行一個 ASCII 詞，不需要讀音。它主要用來讓智慧混輸更穩地認出英文片段。

同步方式

指向同步資料夾

輸入法直接讀寫你指定的詞庫資料夾，同步交給那個資料夾背後的服務，輸入法本身不對外連線。同一個 Apple 帳號用 iCloud 雲碟；不同帳號用私有 git repo，還多了版本歷史。

本機重載

重新載入使用者詞彙

輸入法會用 FSEvents 監看詞庫資料夾，iCloud 同步進來的變動通常會自動生效。若你剛手動改了 data.txt 或白名單想立刻套用，按這個選項即可。

白話流程

加完就好，不用按同步

在任何一台 Mac 新增詞彙，檔案就直接寫進 iCloud 雲碟，其他 Mac 由 iCloud 自動收到。沒有「同步」這個步驟要按。唯一要注意的是不要兩台同時離線編輯，否則 iCloud 會產生衝突副本。

排查結論

更新後若沒看到功能選單

如果切到花椰輸入法後只有勾選，卻沒有出現「關於花椰輸入法」等項目，通常不是你打字方式有問題，而是該 App 還握著舊的輸入法連線。最有效的處理是完整關閉那個 App 再重開。

How To Use

使用方法與熱鍵

下面是目前版本最重要的操作。熱鍵以 macOS 實際偵測到的 modifier flags 為準，尚未嚴格限定左側 Control / Shift。

ControlShift5

加入游標前 5 個字元

游標在 Cloud 的 d 後方時按下，會將 Cloud 加入使用者詞庫。

ControlShift2

加入游標前 2 個中文字

游標在「字尾」後方時按下，會將「字尾」加入使用者詞庫。

同位置同熱鍵

刪除剛加入的詞

同一位置再次按相同熱鍵，會從使用者詞庫刪除該詞，並顯示提示視窗。

Option↑ / ↓

調整候選字順序

候選視窗開著時，把反白的候選字上移或下移一位。只能在同一個讀音內調整，碰到不同讀音的鄰居會發出提示音。

Shift-<>

輸入雙向箭頭

按住 Shift 依序按 - < > 會得到 ↔。只按前兩鍵是 ←，- > 是 →。

輸入法選單

重新載入使用者詞彙

立刻重讀 data.txt 與 smart-mixed-ascii-words.txt。多機同步交給 iCloud 雲碟，不需要在選單裡按任何同步動作。

Install

下載與安裝

目前提供個人測試用 DMG。它可以安裝在從未安裝過此輸入法的 Mac，也可以覆蓋舊版；安裝腳本會停止舊 process、替換 app bundle 並重新啟用輸入來源。

下載 Broccoli SmartInput v1.2.0 DMG 下載 PKG
  1. 打開 DMG，執行 Broccoli-SmartInput-v1.2.0-personal.pkg。
  2. 需要 macOS 13 Ventura 或更新版本。
  3. 若 macOS 顯示「Apple 無法驗證」，對 pkg 按右鍵選「打開」。
  4. 安裝後到「系統設定 > 鍵盤 > 輸入方式」確認花椰輸入法已加入。
  5. 若行為仍像舊版，登出再登入或重開機一次。
  6. 如果打開 DMG 後執行 PKG 碰到困難，請直接使用下方終端機指令，複製貼上即可完成安裝。

Advanced

終端機指令

完整安裝指令（推薦）

用終端機下載可以完全避開 Gatekeeper 的「無法驗證」：curl 取得的檔案不會被加上隔離屬性，瀏覽器下載的才會。

curl -L -o /tmp/broccoli.pkg https://github.com/CloudHua183/Broccoli-SmartInput/releases/download/v1.2.0/Broccoli-SmartInput-v1.2.0-personal.pkg
sudo installer -pkg /tmp/broccoli.pkg -target /
open ~/Library/Input\ Methods/McBopomofo.app

已經用瀏覽器下載好 PKG 的話，先複製到 /tmp 再移除隔離屬性——DMG 是唯讀磁碟區，直接對裡面的檔案下 xattr 一定會失敗：

cp ~/Downloads/Broccoli-SmartInput-v1.2.0-personal.pkg /tmp/broccoli.pkg
xattr -dr com.apple.quarantine /tmp/broccoli.pkg
sudo installer -pkg /tmp/broccoli.pkg -target /

設定多機詞庫同步

詞庫位置可以指向任何會自動同步的資料夾。同一個 Apple 帳號的多台 Mac 用 iCloud 雲碟最省事：

./script/migrate_to_icloud_dictionary.sh

若各台使用不同 Apple 帳號，改用私有 git repo。它同時提供版本歷史，詞庫被誤改時可以回溯：

./script/setup_dict_sync.sh git@github.com:YOUR_NAME/YOUR_DICT_REPO.git
